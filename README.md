# Consumer Shopping Behavior Analytics

## Project Overview

This project analyzes customer shopping behavior using transactional retail data to uncover insights into customer preferences, purchasing trends, subscription behavior, and revenue patterns.

The analysis was performed using:

* **Python & Pandas** for data cleaning and preprocessing
* **SQL (PostgreSQL)** for business analysis queries
* **Power BI** for interactive dashboard creation

The goal of this project is to help businesses improve customer engagement, optimize product strategies, and support data-driven decision making.

---

## Tech Stack

* Python
* Pandas
* SQL (PostgreSQL)
* Power BI

---

## Dataset Information

The dataset contains:

* 3,900 customer purchase records
* 18 columns
* Customer demographics
* Purchase history
* Product details
* Subscription information
* Shipping preferences
* Review ratings

---

## Project Workflow

### 1. Data Cleaning & Preparation (Python)

Performed:

* Missing value handling
* Column standardization
* Feature engineering
* Data consistency checks
* Customer segmentation preparation

---

### 2. SQL Business Analysis

Business questions answered using SQL:

* Revenue contribution by gender
* High-spending discount users
* Top-rated products
* Shipping type comparison
* Subscriber vs non-subscriber analysis
* Customer segmentation
* Revenue by age group
* Top-performing products per category

---

### 3. Power BI Dashboard

Created an interactive dashboard to visualize:

* Revenue by category
* Customer spend vs ratings
* Subscription behavior analysis
* Revenue by age group
* Customer purchase patterns
* Payment distribution insights

Dashboard features:

* Interactive slicers and filters
* KPI cards with customer metrics
* Scatter, treemap, donut, fill map, and area visualizations
* Customer behavior and spending analysis

---

## Key Insights

* Clothing category generated the highest revenue.
* Young adults contributed the highest total revenue.
* Loyal customers formed the majority customer segment.
* Express shipping users showed slightly higher average spending.
* Certain products had significantly higher discount dependency.

---

## Business Recommendations

* Improve customer loyalty programs
* Promote subscription-based benefits
* Focus marketing efforts on high-revenue age groups
* Optimize discount strategies
* Highlight top-rated products in campaigns
